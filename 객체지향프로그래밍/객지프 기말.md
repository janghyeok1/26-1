# 형변환
상향 형변환(upcasting): 자동, 자식 클래스를 부모 포인터로 선언, 자식 함수 사용불가
하향 형변환(downcasting): 부모 클래스를 자식 포인트로 변환

static_cast: 기본 타입, 상속 관계 포인터 변환, 실패하지 않음(컴파일 시간 오류)
dynamic_cast: 상속 관계 포인터 변환, 실패시 NULL, 가상함수 필요
const_cast: const 속성 제거/추가
reinterpret_cast: 상속 관계 없는 포인터
typeid().name(): 객체 타입 식별

# 다형성
정적 바인딩: 컴파일 시간에 결정, 빠름
동적 바인딩: 실행 시간에 결정, 지연 바인딩, virtual
소멸자 virtual로 선언하지 않으면 메모리 누수 문제 발생(부모 클래스 포인터로 자식 객체를 delete할 때 자식 소멸자 미호출)
## 예시-동적 바인딩
parent *p = &obj;
parent &p = obj;

# 전위/후위 연산자
전위: 매개변수 없음, operator++()
후위: 더미 인자로 구별, operator++(int)

# 예외 처리
상황: 잘못된 코드, 부정확한 데이터, 예외적 상황에 의한 런타임 오류(0으로 나누기, 배열 인덱스 초과, 하드웨어 에러)
try: 판정 범위
throw: 예외 던짐
catch: 예외 처리, 항상 구체적 타입 먼저, catch(...)는 마지막
사용자 정의 예외 클래스: 자식클래스 throw, 부모클래스 catch, 다형성을 이용해 자식 throw함수 실행
## 예시-사용자 정의 예외 클래스
public exception {
public:
    virtual const char* what() const noexcept = 0;
};
class MyException : public exception {
public:
    const char* what() const noexcept { return "error"; }
};
try {
    throw MyException();
}
catch (exception& e) { cout << e.what(); }

# 벡터
동적 배열, #include<vector> 필요
push_back(): 맨뒤 추가
pop_back(): 맨뒤 삭제
size(): int, 개수
empty(): bool, 비어있음 여부
vector<int>::iterator it: 반복자, 배열 내부 순회
begin(): 첫 번째 주소(반복자)
end(): 마지막 + 1 주소(반복자)
v[i]: i번쨰 원소
전향 반복자: ++, forward_list
양방향 반복자: ++ --, list, set, map
무작위 접근 반복자: ++ -- [], vector, deque

# 함수 템플릿
일반화: 자료형에 무관하게 동작하는 함수 설계, template<typename T>, template<class T>
특수화: 특정 타입에 별도 구현, template<>
일반 함수와 템플릿 공존 시 일반 함수 우선
## 예시-일반화
template<typename T>
class Box {
    T value;
};
Box<int> b1;
# 예시-특수화
template<>
const char* getmax<const char*>(const char* a, const char* b){
    return (strcmp(a, b) > 0) ? a : b;
}

# 스택
last in first out
push(): 맨뒤 추가, stack[++top] = 10;
pop(): 맨뒤 삭제, value = stack[top--];
isEmpty(): bool, 비어있음 여부, top == -1;
isFull(): bool, 가득참 여부, top == 배열크기 - 1;
