## characteristics of multimedia
digital revolution: web & interacitiy
from passive consumption to user-driven
growth of file size -> advancements  in compression technology
## fundamentals of multimedia
standard: rules and guidelines, De Jure(official) and De Facto(widespread) Standards
### text
ASCII Code: 7bit represent 128 characters + 1bit parity bit, only english
Unicode: universal standard, all languages and scripts
HyperText Markup Language: HTML, logical structure and connect, web
### sound
music, sound effects, speech
represented as a waveform, defined by frequency(pitch) and amplitude(volume)
### image(bitmap)
color and brightness information for every single pixel
JPEG: de Jure, almost no compression, large size
BMP: de Facto, lossy compression, efficient size
### graphics(vector)
not pixels but mathematical equations for lines, curves, and shapes
scalability: file size is measured by graphical complexity, not display size
### animation
illusion of movement, interaction to user input
### video
data-intensive medium
require at least 15 frames per second(fps)
boundary between animation and video is becoming blurred, hybrid form
### data size comparison
text < sound < image < video/animation
12Megapixel photo requires 36MB(12 * 3(3 RGB bytes with a pixel)) of uncompressed data
one minute FHD video(1080p at 30fps) requires 11.2GB(60 * 30 * 1920 * 1080 * 3) of uncompressed data
compression is essential, without compression storing and transmitting files would be impractical
image compression formats: GIF, PNG(lossless for fraphics), JPEG(lossy for photographs)
video compression stardards: MPEG series(1,2,4), H.26x series(H.264/AVC)
### digital media
replacement of analog signals with digital formats
advantage: permanent preservation, ease of use
static media: text, image, graphic
dynamic media: sound, videoo, animation

## digitizing signal
signal: analog to digital
change in magnitude over a single dimension(time)
extening from 1D time axis to a 2D spatial domain(amplitude)
image represented in 3D(x, y, brightness), if you extract a single horizontal line, you get brightness changes along th x-axis, this look link an audio signal.
many principles of 1D signal processing can be extended to 2D image processing
analog, continuous-time signal, discrete-time signal, digital signal
### analog signal
continuous in both time and amplitude
smoothness: differentiable at every moment
### continuous-time signal
signal is defined at all points in time(continuous)
### discrete-time signal
signal is defined only at specific, distinct moments in time(discrete)
### digital signal
discrete in both time and amplitude
defined only at specific points in time, its amplitude can only be one of a finite, predetermined set of values
from nature to computing, Analog-to-Digital conversion(ADC) or Digitization
### how ADC
step1 sampling: in time, the sampling frequency is at least twice the highest frequency in the signal(Nyquist Theorem)
step2 quantization: in amplitude, mapping to the closest value from level(bit depth)
